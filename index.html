Transformative Agreements Journal Discovery Tool (Beta)

This tool aims to assist HKU researchers to discover journals with open access article processing charges covered by transformative agreements (TA). Details about TA can be found at: https://libguides.lib.hku.hk/openaccess/ta.

All data are up-to-date at the time of data collection. Publishers may include and exclude journals without notifying the Libraries. Please refer to the agreement page for latest information.

If you find out any discrepancies between the information provided by this tool and that provided by the publisher, please report them to us via: https://lib.hku.hk/check_form/ask_a_librarian-form/ (To: Open Access).

Some publishers declined to provide journal lists covered by the transformative agreements, which were used for creation of this tool. Please directly refer to the publishers' sites for journals covered. They are:
